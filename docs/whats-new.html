0.1.0 — Initial public release

  • Chat with DeepSeek Harness over ACP from the DSH tool window, with streaming Markdown, tables, collapsible reasoning, tool-call details, plan/todo display and context usage.
  • Create and resume project sessions; restore reasoning and tool results from history. Bridge integration adds session titles, rename/delete actions and ZIP log export.
  • Choose models, reasoning effort, agent presets and permission modes from the composer; approve tool requests in native dialogs or cancel an active turn.
  • Use the / command palette, browse skills and reference project files with @.
  • Install or repair the shared dsh-vscode-bridge profile from the toolbar, with version-aware setup for supported dsh releases and Doctor diagnostics.
  • Run the agent on Linux/macOS, Windows or WSL with automatic path mapping and support for custom environment variables.
  • Includes English and Simplified Chinese interface resources, IDE-aware typography, and chat layouts that adapt to tool-window resizing.

Before you start: use an IDE based on build 243 or newer and Node.js 22.19 or newer on the agent side. Configure a model provider in dsh. The bridge installer requires a POSIX shell (Linux, macOS or WSL); native Windows bridge setup is manual.

See the quick start and dsh/bridge compatibility table.
