DSH Lite brings the DeepSeek Harness (dsh) coding agent into your JetBrains IDE through the Agent Client Protocol (ACP). Ask questions about your project, reference files, follow tool activity, and manage agent sessions without leaving the editor.

Features

  • Streaming chat: Markdown replies with tables, code blocks and copy actions; collapsible reasoning and tool-call cards; plan/todo display and a context-usage meter.
  • Project sessions: create, list and resume conversations, restore reasoning and tool results, rename or delete sessions, and export session logs as ZIP.
  • Agent controls: choose a model, reasoning effort, agent preset and permission mode; review permission requests in native dialogs and cancel a running turn.
  • Commands and context: type / for local actions, native dsh commands and skills; browse the skill catalog or use @ to reference project files.
  • Flexible runtime: run dsh locally on Linux/macOS, in WSL from a Windows IDE, or natively on Windows, with automatic Windows/WSL path mapping.
  • Setup and diagnostics: install or repair the dsh bridge from the toolbar and use Doctor to check the agent runtime and bridge connection.
  • English and Simplified Chinese interface resources.

Requirements

  • An IntelliJ Platform IDE based on 2024.3 (build 243) or newer, such as IntelliJ IDEA, PyCharm, WebStorm or GoLand. Android Studio must also meet this platform build requirement.
  • Node.js 22.19 or newer and DeepSeek Harness on the machine or WSL distribution where the agent runs. Install dsh with npm i -g @deepseek-ai/dsh, launch it through npx, or use a local checkout.
  • A model provider configured in dsh, including any credentials required by that provider. The IDE plugin does not include a model service or API credits.
  • The dsh-vscode-bridge dsh plugin enables session titles/deletion, agent presets, permission modes, workspace grouping, native commands, skills and log export. See the version compatibility table before choosing dsh and bridge versions.

Getting started

  1. Open Settings → Tools → DSH Lite for JetBrains IDE and choose the runtime and dsh command.
  2. Open the DSH tool window and click Install Bridge to create or repair the default acp-vscode profile. The installer requires Linux, macOS or WSL; native Windows users must configure the bridge separately.
  3. Configure your model provider and credentials in dsh. Extra environment is plain-text IDE state, not a credential store.
  4. Start a new session or type a prompt. Use Doctor if the agent does not connect.

For basic ACP chat without the bridge, select the acp profile. Native Windows history import requires a bridge that supports session ZIP export.
